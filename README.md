# Studio - Component Library & Responsive Layout

A responsive, accessible web project expanded with modern CSS features, custom components, and dark mode support.

## Features Implemented

1. **Responsive Breakpoints:**
   - 1 Column on Mobile screens.
   - 2 Columns on Tablet screens (600px - 1023px).
   - 3 Columns on Desktop screens (1024px+).

2. **Component Library (`components.html`):**
   - **Form Elements:** Inputs, labels, buttons, and select dropdowns.
   - **Pure CSS Modal:** Accessible modal built using the CSS `:target` pseudo-class (no JavaScript).
   - **Alert / Notification:** Styled feedback banner for alerts.

3. **Dark Mode Support:**
   - Automatically respects system preferences via `@media (prefers-color-scheme: dark)`.
   - WCAG AA compliant text and surface contrast.

4. **Accessibility:**
   - Built to meet Lighthouse accessibility score standards (> 90).
